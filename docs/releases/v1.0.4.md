# Release Notes — v1.0.4

**Release Date:** 2026-02-05

## Summary

Maintenance release addressing CI/CD workflow issues and minor tenant access improvements. No schema changes.

## Changes

### CI/CD Pipeline

- Disabled `generate-changelog` job dependency in production deploy workflow — job was failing on API rate limits and blocking release creation
- Disabled Release Drafter auto-labeling on PR events — conflicting with manual release process
- Both features parked for future re-enablement once rate limiting and token permissions are resolved

### Tenant Permissions

- Corrected group role permissions for tenant members to access content within their assigned Tenant Access Group
- Members can now view/edit content scoped to their group without requiring elevated site-wide permissions

### Admin Theme Assets

- Added correct favicon and logo images to Gin admin theme configuration
- Replaces placeholder assets from initial theme setup

## Upgrade Notes

No manual intervention required. Standard deploy process applies.

## Known Issues

- `create-release` job may fail to push VERSION file update to `main` due to branch protection rules — manual VERSION bump may be needed for next release. This does not block normal CI processes.
